# Brawl Arena Online

Android demo app with an updated arena-style main menu.

## Build APK
GitHub Actions builds a debug APK on every push to `main`.
Open the **Actions** tab and download the `Brawl-Arena-Online-APK` artifact from the latest successful run.

This build currently contains the menu, fighter/shop/profile panels and a demo play screen. Online matchmaking and a game server are not implemented yet.
